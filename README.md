## 🚀 Featured Project

### [TalentHub AI](https://github.com/sosdev-del/TalentHub)

> *Showcase Your Talent. Discover Your Opportunity.*

A cross-platform (Android/iOS) app where talented individuals build professional profiles, upload content, and get discovered by recruiters, sponsors and mentors — ranked by **merit, not popularity**.

| | |
|---|---|
| 🤖 **AI engine** | Recommendations, NLP search, auto-tagging & content moderation (OpenAI) |
| 💬 **Realtime** | Chat with read receipts, live notifications (Supabase Realtime + FCM) |
| 📊 **Analytics** | Views trend, engagement charts, admin KPI dashboard (fl_chart) |
| 🔐 **Security** | JWT auth + role-based access control via PostgreSQL RLS |

`Flutter` `Riverpod` `go_router` `Supabase` `PostgreSQL` `OpenAI API` `Firebase Cloud Messaging`

▶️ Runs in **demo mode out of the box** — clone, `flutter run`, no keys needed.
